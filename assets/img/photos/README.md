# Real workshop & part photos

Put photographs of **your own** workshop, machines and parts here (never stock photos
presented as yours). Export each photo as AVIF + WebP at 1×/2× widths, for example:

    photos/workshop-1280.avif   photos/workshop-1280.webp
    photos/workshop-2560.avif   photos/workshop-2560.webp

Then point the matching `<picture>` on the page at these files — see
"Use real workshop photos" in the README for the exact steps.
